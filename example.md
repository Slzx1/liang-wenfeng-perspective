  第一，价格。 V2 把 API 打到输入 1 元、输出 2 元每百万 token，几天之内国内几家陆续跟了。这不是促销，是架构把推理成本降 
  下来了，价格才有空间。结果就是，普通人和小公司第一次用得起接近前沿的模型。                                            
                                                                                                                        
  第二，开源。 R1 用 MIT，V3、V4                                                                                        
  开放权重。开源不只是把模型送出去，更是让它变成公共品：云厂商能部署，开发者能改，DeepSeek                              
  成了事实标准。全球开源生态里，从此多了一个前沿选项。                                                                  
                                                                                                                        
  第三，成本想象。 V3 那次成功预训练 run 的 GPU 成本是 557.6 万美元——注意，这只是最后一次 run，不含前期实验、后训练和推 
  理，更不是公司总成本。但它打破了一个假设：前沿模型只能由巨头用几十亿美元堆出来。这个假设一破，很多团队开始重新算账。  
                                                                                                                        
  第四，组织想象。 两三百人，没有                                                                                       
  KPI，大部分是本土年轻人。它证明前沿竞争不一定要靠几千人的大兵团，聚焦和人才密度也能打。                               
                                                                                                                        
  第五，心理上的。 中国 AI 原来默认是跟随者；V3、R1 之后，至少有一部分人开始相信，原创架构和开源可以出自中国团队。这个变
  化没有那么整齐，也不是我们一家做的，但确实发生了一点。                                                                
                                                                                                                        
  怎么改变的？不是靠一个秘密，是三件事叠加：成本是根，开源是放大器，聚焦是组织保障。单做一件，效果都有限。再加上时机——R1
  出来的时候，推理模型还很贵、还很闭源，对比太强。App 只是让普通人看见了这件事，它本身不是目的。                        
                                                                                                                        
  但也要说清楚没改变什么：没有解决 AGI，没有解决芯片依赖；2026 年 V4 也承认落后闭源三到六个月；多模态、Agent、产品都不是
  我们最强的地方，稳定性也出过问题。准确地说，我们改变的是价格、开放程度和“谁能做前沿”的想象，不是智能的上限。          
                                                                                                                        
  二、资本结构是不是原因                                                                                                
                                                                                                                        
  先纠一个说法：不是我“融”了 200 亿，是公司首轮融了约 510 亿，我个人出了约 200                                          
  亿，是最大单一出资方。外部资金进的是我管理的有限合伙，没有投票权，五年锁定；国家 AI                                   
  基金是例外，它有投票权。这些是媒体口径，官方没有逐项确认。                                                            
                                                                                                                        
  融资是不是我们走不同路线的原因？不是。路线在融资之前就定了。 2023 到 2025 年，我们没融过资，靠幻方的现金流和一万张    
  A100；开源、低价、不做应用，都是在那时候定的。2026 年融资，我给的理由是团队期权和稳定性，不是改路线（2026             
  年闭门会，网传实录，未官方确认）。融资是结果，也是护栏，不是发动机。                                                  
                                                                                                                        
  真正的因果关系在另一头：早期没有外部资本，才没有季度的回报压力，才能做“不赚暴利、开源、不做应用”这些反直觉的决定。这个
  自由来自幻方的现金流，不是来自 200 亿。200                                                                            
  亿的作用是保住控制权，让资本进来以后，方向不被资本带走。经济利益可以让，控制权不能让。                                
                                                                                                                        
  这里要分三层看。我讲的融资理由是团队稳定；外界能看到的动作是首轮约 510 亿元融资、个人出资约 200                       
  亿元、外部资金没有投票权、五年锁定，同时扩招、买卡、设产品部、筹备                                                    
  IPO；我没有承认的，是从“不融资”到“克制地资本化”、从“不做应用”到产品部、从“不上市”到筹备 IPO                           
  这些手段变化。我用更高的目的解释它们，但没有说路线变了。看动作比听口号可靠。                                          
                                                                                                                        
  和别家比，差别不是道德，是账本。OpenAI 有微软和回报压力，必须收前沿的租，所以闭源；Anthropic 有 Google、Amazon        
  和安全叙事，所以闭源加企业 API；Kimi、MiniMax 是 VC 支持的挑战者，开源是最便宜的                                      
  distribution；智谱有企业和地方资源，开源加国产算力；豆包有字节的现金流和流量，可以闭源、可以 go                       
  wide。每一家的路线，都是它资本结构的函数。                                                                            
                                                                                                                        
  所以“后人”这个说法不太准。他们不是沿着我们的路走，而是在解自己的方程。大多数时候，开源是挑战者的武器，闭源是守成者的武
  器；有流量的可以闭，没流量的只能开。DeepSeek                                                                          
  的特殊性在于：它同时是挑战者、有幻方的现金流、又选择了不融资。这三个条件同时成立的公司，很少。                        
                                                                                                                        
  DeepSeek 改变的不是 AI 的方向，是 AI 的价格、开放程度，和“谁能做前沿”的想象。资本结构不是路线的原因，是路线 
  的护栏。路线在融资之前就定了；融资只是让它能走得更远，不至于被资本带偏。
