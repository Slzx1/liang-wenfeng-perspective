国产大模型龙头DeepSeek正在迅速迭代组织结构。
有消息称，DeepSeek最近将Harness团队以及Web、App、Platform 团队整合成“产品部”，负责公司的所有的产品、设计和研发工作，崔添翼任产品部负责人。
10月16日，崔添翼向澎湃新闻记者表示，该消息属实。
公开资料显示，DeepSeek的Agent Harness团队组建于今年3月，负责人崔添翼毕业于浙大计算机专业，拥有6枚ACM亚洲区域赛金牌，曾在顶级量化机构JaneStreet任职九年，今年3月加入DeepSeek。
所谓Harness，是指围绕大语言模型构建的一套软件支撑框架，旨在帮助AI Agent管理和执行更加复杂的任务。简单来说，它可以被理解为让一个大模型真正成为Agent所需要的整套运行系统。
8月13日，DeepSeek Harness v0.1（简称DSH）开发者预览版正式向全球开发者开放测试，并同步以MIT协议公开源代码。项目发布后，迅速在X等社交平台引发开发者热议，不到24小时内，在开发社区GitHub狂揽超过7万颗星。
10月3日，DeepSeek Harness发布新版本，强化插件化和跨平台能力，加入实验性Claude Code Mods兼容层——这也意味着，美国AI巨头Anthropic旗下Claude Code开发的部分扩展功能，理论上可以经过适配后在DeepSeek Harness的框架里运行。
崔添翼表示，自己每天工作的相当一部分时间都用于为DeepSeek招人和面试，DeepSeek的目标是实现AGI，DeepSeek Harness组的目标就是从Harness的角度推进AGI。
在他看来，只有做创新的事情才是真正“推进AGI”的事情，“如果我们抄一个Claude Code，或者抄一个Codex，做一个和其它某些Agent Harness从技术理念到用户体验上都没啥区别、完全差不多的产品，那一定不是推进AGI的事情。”
“推进AGI的事情一定是创新的事情。这次Claude Code Mods的兼容实验，就是我们通过一个具体实现，检验DSH插件系统扩展能力的一次尝试。在DeepSeek Harness团队，我们希望能做出一些世界级的创新，希望能做出一些影响业界发展、影响大家如何看待和定义AgentHarness这一新生事物的创新，希望可以做出一些让世界上的AI巨头也会认可和跟进的创新。”崔添翼提到。
DeepSeek最近“崩”了快5小时也引发了广泛关注。10月15日，DeepSeek开放平台发布服务恢复及补偿通知称，北京时间2026年10月15日8:11至13:04期间，DeepSeek服务系统出现故障，导致该时段内API服务无法正常使用。“对于此次故障给您带来的不便与困扰，我们深表歉意。我们已第一时间启动针对服务稳定性的全面排查和彻底整改，全面梳理并剥离单点依赖，坚决杜绝同类问题再次发生。”
DeepSeek表示，作为补偿，将按账号7日内（10.8-10.14）的消耗金额以赠金形式全额返还，赠金自动到账，API计费扣款先从赠金账户扣除。“此次故障对您造成了影响，我们再次致歉，感谢您一直以来的信任与支持。”
澎湃新闻记者在社交平台上发现，不少用户晒出了DeepSeek的退款补偿金额截图，百元到千元不等，甚至还有用户晒出了超过7万元的退款截图，一时间晒DeepSeek退款成了AI社群的新潮流，有用户笑称：“突然对DeepSeek的崩溃没有怨言了。”
澎湃新闻记者 范佳来 实习生 沈玥彤
