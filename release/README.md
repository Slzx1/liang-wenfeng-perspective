## 使用规则

1. **优先一手材料**：`transcripts/` 中的 2019 演讲、2023/2024《暗涌》专访、2026 闭门会实录，是引语的主要来源。
2. **2026 闭门会实录**（`transcripts/2026-05-20-投资者交流会-录音文字稿.md`）为网传 ASR+AI 整理稿，参投机构向媒体核实会议存在，但 DeepSeek 官方未确认；只用于分析思维过程，不作为精确数字依据。
3. **媒体文章**保留 URL、发布日期、抓取日期、可信度标注。付费墙文章只保存可得摘要与关键引文。
4. **`articles/_raw_captures/`** 是调研 Agent 抓取过程中的原始网页、arXiv HTML/XML 与提取文本（含 `tmp/` 子目录），保留用于追溯，命名未统一；正式引用以 `articles/` 下带日期和来源的中文命名文件为准。
5. **伪引与失真**：2025 年除夕署名「梁文锋」的知乎长文为假冒账号；「原创式创新」「从0到1」「第一性原理」等不是他的原话。详见 `references/research/01-writings.md` 与 `03-expression-dna.md` 的伪引清单。
